# Code of Conduct

## Our standard

Everyone interacting in this repository — issues, pull requests, discussions, code review — is expected to act professionally and respectfully.

**Expected behavior:**

- Be respectful and constructive in feedback.
- Focus criticism on the code and ideas, not the person.
- Accept disagreement gracefully; not every suggestion will be adopted.

**Unacceptable behavior:**

- Harassment, insults, or personal attacks.
- Discriminatory language or behavior of any kind.
- Publishing others' private information without consent.

## Enforcement

Violations may be reported to the repository owner. Reports will be reviewed and may result in a warning, temporary restriction, or permanent removal from the project, at the maintainer's discretion.

## Scope

This applies to all project spaces — issues, pull requests, code review comments, and any other official communication channel tied to this repository.
