## Client architecture notes

- **Routing**: `client/src/App.jsx` implements a dependency-free router using `window.history.pushState` and `popstate` events; pages are code-split with `React.lazy`.
- **Context providers**: `ThemeContext` (dark/light, `localStorage` key `jodhpur_theme`), `InquiryContext` (commission drawer state, `jodhpur_inquiry_list`), `SocketContext` (WebSocket lifecycle with exponential reconnection).
- **3D viewer**: `ThreeViewer.jsx` renders products with studio lighting, soft shadows, orbit controls, exploded CAD joinery animation, and PBR finish switching; disposes all WebGL resources on unmount.
- **Admin components** (`client/src/components/admin`): `OverviewCards`, `ProductTable`, `ProductEditor`, `OrdersPanel`, `QuotesPanel`, `AnalyticsPro`.

## Server architecture notes

- **`server/middleware/security.js`**: `helmetMiddleware` (CSP tailored for 3D canvases, fonts, WebSockets), `additionalSecurityHeaders`, `apiLimiter` / `quoteUploadLimiter` / `authLimiter`, `sanitizeInput`, `piiScrubbingLogger`.
- **`server/middleware/auth.js`**: `requireAuth` verifies `Bearer <token>` JWTs, attaches decoded claims to `req.user`.
- **`server/middleware/requireRole.js`**: RBAC gate for mutating routes.
- **`server/middleware/upload.js`**: Multer disk storage with strict extension whitelist and a 50MB size ceiling.

See [docs/architecture.md](./architecture.md) for the full API route table and request/response flow.
